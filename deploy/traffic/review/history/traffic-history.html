용어 부록

  • 캐시(cache): Cloudflare가 응답을 저장해 원본 서버 호출 없이 바로 주는 기능
  • 서버 렌더링(server-side rendering, SSR): 서버가 HTML을 만들어 주는 방식. 여기서는 Next 서버가 Express를 호출한다
  • 크롤러(crawler): 웹 페이지를 자동으로 읽어 가는 프로그램
  • 메타 크롤러(meta-webindexer): User-Agent에 meta-webindexer가 들어 있는 크롤러. User-Agent는 위조할 수 있다
  • User-Agent(UA): 요청을 보낸 프로그램이 스스로 밝히는 이름
  • 요청 수 제한(rate limit): 짧은 시간에 요청이 너무 많으면 막는 규칙
  • 429 응답(Too Many Requests): 요청이 너무 많아 거절했다는 응답
  • 499 응답(client closed request): 서버가 답하기 전에 요청자가 연결을 끊었다는 기록
  • robots.txt: 크롤러에게 읽지 말아야 할 주소를 알리는 파일. 강제력은 없다
  • nofollow: 링크를 따라가지 말라고 크롤러에게 알리는 표시
  • 순방문자(unique visitor): Cloudflare가 세는 서로 다른 방문자 수
