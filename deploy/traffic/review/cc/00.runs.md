# Phase CC 실행 대장 (00.runs.md)

## 머리 메모

> 작성: data-analyst, 2026-10-14. 저장된 파일만 읽었다. 코드, git, 네트워크는 쓰지 않았다.

- 이 대장은 실측만 적는다 (`rules/measurement.md` §4). 추정은 "추정"이라 적는다.
- 한 행 = `runs/` 아래 실행 폴더 하나. `x_` 폴더는 뺀다 (지금 없음).
- 판정 기준은 `criteria.md`다. 판정 파일(`verdicts.json`)은 없다. 판정 칸은 요약 파일과 메모를 가리킨다.
- 배포 web sha: manifest `web_sha`가 있으면 그 값이다. 없으면 dispatch 기록이다. 칸에 출처를 적었다.
- 굵은 칸 = 앞 행과 바뀐 web sha 또는 code_sha. 하네스 HEAD는 굵게 하지 않는다.
- 이 대장은 QW1, QW2, U1, U2 배포 뒤에 늦게 썼다. `criteria.md` 머리 메모와 같은 사정이다.
