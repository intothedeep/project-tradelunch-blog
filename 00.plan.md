## Product Identity

Personal portfolio + blog for Taek Lim (GitHub: tradelunch), one Next.js 16 monorepo,
domain `my.prettylog.com`. Surfaces:

1. **Blog / portfolio** — curated multi-user technical posts (Clerk auth). Posts are authored
   either by the Python publishing agent (`apps/blog_agent`, direct-write) OR via the in-app
   authoring UI (`/write`, Phase D2 + the authoring UX cycle — create/edit/autosave/thumbnail UX
   shipped).

(2026-07-09); see the Finance-track MOVED stub below.
