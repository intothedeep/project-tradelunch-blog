## Product Identity

Personal portfolio + blog for Taek Lim (GitHub: tradelunch), one Next.js 16 monorepo,
domain `my.prettylog.com`. Surfaces:

1. **Blog / portfolio** — curated multi-user technical posts (Clerk auth). Posts are authored
   either by the Python publishing agent (`apps/blog_agent`, direct-write) OR via the in-app
   authoring UI (`/write`, Phase D2 + the authoring UX cycle — create/edit/autosave/thumbnail UX
   shipped).
2. **Log** — Threads-style personal microfeed (`/log/[username]`, Phase Y, shipped).

The **financial dashboard surface moved to the separate `project_tradelunch_finance` repo**
(2026-07-09); see the Finance-track MOVED stub below.

## Tech Stack (locked)

- Next.js 16 App Router, TypeScript strict; Tailwind v4, Radix UI, shadcn/ui, lucide-react
- Turborepo monorepo: `apps/dashboard_client_web`, `apps/dashboard_server`, `apps/blog_agent`, `packages/*`
- Jotai, TanStack Query v5, next-intl (recharts/lightweight-charts removed — `01.status.md` 2026-07-13 refactor(hygiene))

- Images: OCI Object Storage via the provider-swappable storage module (`STORAGE_PROVIDER`)
- Publishing: Python LangGraph agent (`apps/blog_agent`), `uv`-managed
- pnpm 9.15.9; prod = Vercel (two projects, one repo) → moving to one GCP e2-micro VM + 1 Cloudflare Tunnel (2 hostnames) + PM2 (Phase GCP, #47–#53)
